# DECO Lab Work ⚡

This repository contains digital electronics and computer organization circuit designs, simulations, and laboratory reports at IILM University.

## 📁 Repository Structure

* **Circuit Files:** `.circ` files created and simulated using Logisim.
* **Screenshots:** Visual captures of logic gates, adders, and multiplexers.

## 🛠️ Key Topics Covered

* **Logic Gates:** Implementation of basic gates and universal gates (NAND/NOR)
* **Combinational Circuits:** Half Adder, Full Adder, and Multiplexers (Mux 4 to 1)
* **Circuit Simulation:** Testing and verifying truth tables via Logisim
